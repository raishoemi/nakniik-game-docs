Tags are a tool to group NPC's together for the sake of simplifying who can perform a favor for you.
This is best explain with examples:

Milly Booby Brown:
- Upper-class
- WHORE!

Mr. Bombastic:
- Upper-class
- Performer

And so forth.
So when Mr. Bombastic owes you a favor, you can utilize it as a favor from either "Upper-class" (if you need an tax-breaks) or "Performers" (if you need a performance)

### Multiple Tags
- Some tags share other tags - for example someone can be both `PERFOMER` and `UPPER_CLASS`
- Other tags will not intersect - Someone **cannot** be both `UPPER_CLASS` and `LOWER_CLASS`.
